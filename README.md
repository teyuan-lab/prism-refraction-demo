# Interactive Prism Refraction

A standalone English-language geometric optics demonstration.

- Incident angle slider from 0 to 90 degrees
- Adjustable prism apex angle and refractive index (default 1.5)
- Ray diagram with incidence and deflection angle labels
- Total internal reflection tracing
- Deflection versus incident angle curve with a live data point

Open `index.html` directly in a browser. No installation or build step is required.

The surrounding medium is air (n = 1). The model omits dispersion and partial reflection. The 90-degree endpoint represents the grazing-incidence limit.
